# vibe-harness-v5

A deployable Agent Harness template for Codex, Claude Code, and other coding agents.

It provides:

- `AGENTS.md` v5 execution contract
- Memory Bootstrap registry
- Lessons governance and promotion index
- `vibe-memory-check`, `vibe-evolve`, `vibe-guard`, `vibe-xcheck` skills
- Codex hooks and Claude Stop hook
- Memory consistency and lesson evolution scripts

Start with `README_DEPLOYMENT.md`.
