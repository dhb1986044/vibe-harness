# INIT: Intent → PRD → Plan → Confirm → Execute → memory-bank

Use this when starting a new repo or a fresh goal.

## Steps
1. Understand raw intent
2. Ask >=9 clarifying questions (grouped)
3. Draft PRD with Acceptance Criteria (AC)
4. Produce implementation plan (plan-only) with verification per step
5. Confirm: convert into executable task list for the executor
6. Execute (optional): only after plan approval
7. Doc-sync: persist/update `memory-bank/` and `plans/`
