# 计划审查（Plan Review）—闭环模板

## 核心闭环
1) vibe-plan / vibe-init 产出 PLAN-ONLY（含验证）
2) vibe-review 审查计划（Staff Engineer 视角）
3) 修订计划 → 进入 EXEC

## 审查维度（清单）
- 需求/验收标准：是否可验证？是否遗漏非目标？
- 方案：是否至少 2 个方案对比？是否有回滚？
- 影响面：接口/数据/依赖/性能/安全
- 验证：单测/集成/回归/观测
- 交付：commit 颗粒度、发布顺序、风险点

## 输出要求
- P0/P1/P2 缺陷分级
- 必须给出“最小可行修订”而不是泛泛建议
