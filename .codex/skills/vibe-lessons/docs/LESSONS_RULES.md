# Lessons 记录规范

## 本仓库采用的格式
- 主库：`docs/LESSONS.md`
- 归档库：`docs/LESSONS_ARCHIVE.md`
- 规则文件：`docs/LESSONS_RULES.md`

## 读取协议
1. 先读取索引，不默认通读全文。
2. 默认展开 `Pinned` + 最近 `5~10` 条 `活跃` 条目。
3. 命中标签 / 关键词 / 影响文件时，再按需展开历史活跃条目或 archive。

## 正文格式
本仓库默认使用紧凑格式：

```markdown
## L{n} 标题
- 场景：...
- 风险：...
- 修复策略：...
- 可复用模式：...
- 建议升级为 Guard/XCheck 规则：...
```

## 索引字段
| # | 标题 | 标签 | 优先级 | 状态 |
|---|---|---|---|---|

状态只允许：`活跃` / `已归档` / `Pinned`

## 自动归档
- 活跃条目软上限：`12`
- 写入后若活跃条目 `> 12`，自动触发归档检查
- 默认把活跃窗口压回 `8~10`
- `Pinned` 不参与默认归档
- legacy 迁移允许一次“基线迁移归档”
