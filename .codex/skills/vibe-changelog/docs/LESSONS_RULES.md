# Lessons 记录规范

## 教训记录格式

每条教训必须包含以下结构（参见 `docs/LESSONS.md` 中 L1-L9 的实际格式）：

1. **标题行**: `## L{n}: {简洁标题} ({优先级 P0/P1/P2})`
2. **元信息**: 日期 / 来源 / 影响文件
3. **根因分析**: 2-4 句话描述问题本质
4. **反模式**: 引用块格式，一句话概括「不应做什么」
5. **最佳实践**: 编号列表，每条可操作

## 分类标签（必选 1-2 个）

`[Prompt]` `[PP]` `[Schema]` `[Process]` `[Rule]` `[Skill]`

## 容量管控

- **活跃条目上限**: 15 条
- **归档标准**: 教训已被 Prompt/PP/Rule/Skill 固化（引用具体文件为证）
- **归档目标**: `docs/LESSONS_ARCHIVE.md`
- 索引表保留已归档条目行（状态标记为「已归档」）
