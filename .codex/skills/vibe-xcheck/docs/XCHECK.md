# P6-B：模型交叉复核（Second Model / Second Session）

## 目标
用“第二双眼”降低返工：计划、补丁、数据结论都做交叉复核。

## 复核策略（推荐）
### 1) 计划复核（Plan Review）
- 主会话：vibe-init / vibe-alpha 产出计划
- 复核会话：vibe-review 审查并给 P0/P1/P2

### 2) 补丁复核（Patch Review）
- 主会话：按计划实现
- 复核会话：vibe-omega 做审计（是否越权、是否缺验证、是否破坏约定）

### 3) 数据结论复核（Data Check）
- 主会话：查询与解释验证数据
- 复核会话：要求“反证”——给出最小反例查询（如果反例成立则推翻结论）

## 操作建议（Windows）
- 开两个终端/两个 worktree：一个写代码，一个只审查/只验证
- 或同仓库不同会话：主会话负责执行，复核会话只读审计
