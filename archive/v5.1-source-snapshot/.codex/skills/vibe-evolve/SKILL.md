# vibe-evolve

Use after writing or updating LESSONS.

Run:

```bash
python scripts/evolve_lessons.py --write
```

Then review:

- evolution/lesson-index.json
- evolution/promotion-log.md
- evolution/candidates/

Do not create a new skill from a single low-frequency lesson.
