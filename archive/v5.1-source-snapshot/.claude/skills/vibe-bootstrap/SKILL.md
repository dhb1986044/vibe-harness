# vibe-bootstrap

Use when a project is new or intentionally being initialized from scratch.

Do:

1. Create AGENTS.md.
2. Create memory-bank files.
3. Create docs/LESSONS.md, docs/AI_CHANGELOG.md, evolution files.
4. Install core skills and hooks.
5. Run `python scripts/check_memory_consistency.py --strict`.

Do not use for unmanaged historical projects. Use `vibe-discovery` instead.
