# vibe-guard

Use when a change touches core logic, schema, API, CLI, hooks, AGENTS, memory, publishing, dependencies, or CI.

Output:

- Risk level: low / medium / high
- Key assumptions
- Rollback plan
- Residual risks

If risk is high, split the task or ask for explicit approval.
